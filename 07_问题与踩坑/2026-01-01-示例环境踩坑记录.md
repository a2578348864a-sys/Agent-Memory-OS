# 2026-01-01 示例：Windows 环境下 CMD 与 PowerShell 中文乱码

## 问题现象
在 Windows 默认环境下使用 CMD 脚本传中文参数给 PowerShell 时，出现乱码解析错误。

## 原因分析
CMD 默认代码页为 936（GBK），而 PowerShell 5.1 解析 UTF-8 无 BOM 文本时容易按系统编码解析，导致中文双字节被破坏。

## 解决办法
1. `.cmd` 脚本坚持全纯 ASCII 原则，避免传中文字符串。
2. PowerShell 脚本统一使用 UTF-8 with BOM 保存。
