# raw/ 目录说明

`raw/` 存放**外部原始资料**：外部文章、官方文档、抓取/导出的笔记等未经提炼的素材。

## 规则

1. `raw/` 只放原始资料，不做加工；加工后应提炼为知识卡片。
2. 草稿卡（`02_知识卡片/_drafts/`）的 frontmatter `source` 应指向 `raw/`，例如 `raw/2026-08-10-外部资料.md`（lint 对草稿强制要求 `source` 以 `raw/` 开头）。
3. `raw/` 中的内容**不能直接成为正式卡**；必须按流程：放入 `02_知识卡片/_drafts/` 草稿 → 用户确认 → `05_代码与配置/草稿卡提升器.ps1` 原子提升（Lint + 提升门禁）。
4. 正式卡来源优先指向 `raw/` 原始资料，其次才是项目内部执行记录（`04_执行记录/` 等）。
5. 快照备份（`05_代码与配置/知识库本地快照备份.ps1`）会连同 `raw/` 一起归档，请勿删除本目录。
